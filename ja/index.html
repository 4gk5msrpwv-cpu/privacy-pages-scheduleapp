プライバシーポリシー

1. 概要

ScheduleApp は家庭向けのスケジュール・ToDo 管理アプリで、スケジュール作成、時刻になったときのリマインダー、ファミリーグループ共有、ホーム画面ウィジェット／ライブアクティビティ表示などを提供します。個人開発者（{dev}）が独立して開発しており、自前のサーバーもバックエンドデータベースも持ちません。本ポリシーは、私たちがあなたの情報をどのように（実際には：一切）扱わないかを説明します。

2. 収集する情報：なし

ScheduleApp は個人情報を一切収集しません。具体的には：

  • 登録もログインも不要。アカウント体系はありません。氏名・メールアドレス・電話番号・連絡先・位置情報・写真・その他の識別子を要求・取得しません。家族の区別には Apple が提供する匿名の iCloud レコード名のみを使用し、氏名・メール・電話番号は含まれません。
  • データはあなたの iCloud にだけ保存。作成したスケジュール・ToDo・リマインダー設定は、あなたの Apple ID の iCloud プライベートデータベース（Apple CloudKit、コンテナ iCloud.com.frankzhou.ScheduleApp）に保存されます。データはあなたに帰属し Apple が保管し、開発者はアクセス・読み取り・書き出しともできません。
  • ファミリーグループ共有は Apple CloudKit の共有機能（CKShare）によるものです。自分が作成したスケジュールは自分の iCloud プライベートデータベースに保存され、ファミリーグループに公開したときだけ Apple 提供の iCloud 共有データベースに入り、招待した家族だけが閲覧できます。共有範囲は完全にあなたが管理し、いつでも停止できます。

デバイス機能とシステム権限：

  • 通知 — 自分で設定したローカルリマインダー（スケジュール/ToDo のアラーム）専用です。広告・マーケティング content は一切ありません。リモート（サイレント）通知は iCloud 同期のトリガーとしてのみ使用され、可視の通知を表示したりスケジュール内容を運んだりしません。
  • ウィジェット／ライブアクティビティ — ウィジェットやロック画面のデータは、デバイス上の App Group コンテナ経由でアプリとウィジェット間で受け渡されます。デバイスの外に出ず、サーバーへアップロードされることはありません。
  • 要求しない権限 — 位置情報・連絡先・カメラ・マイク・写真ライブラリ・App トラッキングの権限は要求しません。上記以外の権限宣言はありません。

3. サードパーティ・トラッキング・広告：すべてなし

  • サードパーティコードは一切なし — 広告 SDK・解析 SDK・クラッシュレポート・アトリビューション・マーケティングpush コンポーネントなど、サードパーティ SDK に依存しません。
  • トラッキングなし — IDFA なし、App トラッキングの許可ダイアログなし、アプリ間/サイト間トラッキングなし、トラッキング Cookie・デバイスフィンガープリント・ローカル識別子なし。
  • データの売買は一切しません — ユーザーデータを販売・共有・取引せず、いかなる形のデータ収益化も行いません。広告やプロファイリングにも使用しません。
  • ネットワーク通信はすべて Apple 向け — 本ポリシーページの読み込みを除き、アプリの全ネットワーク通信は iCloud/CloudKit 同步（同期）であり、Apple のプライバシーポリシーに準拠します。このページはサードパーティの静的ホスティング（GitHub Pages）でホストされています。このページの読み込みは、Apple 以外のサービスへの唯一の通信であり、アカウント情報やデバイス識別子は一切送信されません。
  • アプリのプライバシーマニフェスト（PrivacyInfo.xcprivacy）で、ユーザーをトラッキングせずトラッキングドメインを使用しないことを App Store に宣言済みです。

4. 子どものプライバシー

  • ScheduleApp は一般向けの家庭用ツールであり、子ども向けに設計されたアプリではなく、特定年齢未満の子どもに向けた販売促進も行いません。
  • 本アプリは誰の（子どもを含む）個人情報も収集しません。子どもが作成したスケジュールや ToDo も、その子（または保護者）自身の iCloud アカウントに保存されるだけで、開発者はアクセスできません。
  • 保護者が Apple「ファミリー共有」で子ども用 Apple ID を作成・管理する場合、そのアカウントは Apple のルールに従い、共有は保護者の管理下にあり、いつでも停止できます。
  • 知的な範囲でも未成年者の情報を収集してしまった（本アプリの構造上起こり得ません）と思われる場合は、{mail} までご連絡ください。直ちに削除いたします。

5. データの保存・セキュリティ・削除

  • すべてのデータはあなたの Apple ID の iCloud アカウント内にあり、Apple の暗号化とアクセス制御で保護されます。サーバー側のコピーは一切保持しません。（中国本土の Apple ID の iCloud データは、Apple の中国におけるクラウド運営者 GCBD（雲上貴州）が Apple のポリシーに従って運用しています。）
  • アプリを削除しても iCloud データは自動的には消えません（新しいデバイスでの復元のため）。すべて消去するには：iPhone/iPad の「設定 → [あなたの名前] → iCloud → ストレージを管理 → ScheduleApp → データを削除」から削除するか、アプリ内でスケジュール/ToDo とファミリーグループを削除するか、{mail} までメールでご依頼ください。
  • 少量の設定（言語や表示設定など）はデバイス内だけ（システムの UserDefaults）に保存され、デバイスの外に出ず、iCloud にも同期されません。
  • ローカルファースト：iCloud をオフにしていても、ネットワークがなくても、アプリはオフラインで動作し、ローカルリマインダーは通常どおり鳴ります。
  • Apple ID とデバイスのパスコードは厳重に管理してください。このデータを守る第一の保護です。

6. ポリシーの変更

本ポリシーを変更する場合は、このページを更新し、上部の「発効日」を改訂します。重要な変更（例：新しいデータ収集の導入）は、アプリ内でもわかりやすくお知らせします。最新版を確認するため、定期的に本ページをご覧ください。

7. お問い合わせ

本ポリシーまたはあなたのデータに関するご質問・ご苦情・削除のご依頼は、{mail} までメールください。通常 3 営業日以内に返信します。

サポート・よくある質問

データが消えることは？いいえ。データはあなたの iCloud にあり、Apple アカウントとともに保持されます。アプリを削除しても iCloud データは消えません。
新しい iPhone に機種変更したら？同じ iCloud アカウントでサインインし、本アプリの iCloud 同期を有効にすると、データは自動的に表示されます。
家族に見えるのは？ファミリーグループに公開したスケジュールだけです。未公開のスケジュールはあなたの iCloud プライベートデータベースにあり、他人には見えません。
開発者はスケジュールを読めますか？いいえ。データはあなたの iCloud にあり、開発者にアクセス手段はありません。
リマインダーが鳴らない？「設定 → 通知」で本アプリの通知が許可されているか、アプリ内でリマインダーが有効かをご確認ください。iCloud 未ログイン時はスタンドアロンモードで動作し、ローカルリマインダーは有効です。
