一句话总结： 本应用不收集任何个人信息：无账号系统、无开发者服务器、无第三方统计或广告 SDK。你的日程、待办与提醒设置只保存在你自己的 iCloud 私有数据库（Apple CloudKit）中；家庭共享基于 Apple CloudKit 共享能力（CKShare）实现，开发者无法读取或导出你的数据。

隐私政策

一、概述

日程提醒（ScheduleApp）是一款面向家庭场景的日程与待办管理应用，提供日程创建、到点提醒、家庭组共享以及主屏幕小组件/灵动岛展示等功能。本应用由个人开发者（{dev}）独立开发，无自建服务器、无后台数据库。本政策说明我们如何处理（事实上是：不处理）你的信息。

二、我们收集哪些信息：不收集

本应用不主动收集任何个人信息。具体而言：

  • 无需注册、无需登录：本应用没有账号体系，不要求也不获取姓名、邮箱、手机号、通讯录、位置、相册或任何身份标识。家庭成员由 Apple 提供的匿名 iCloud 记录名区分，该标识不含姓名、邮箱或电话号码。
  • 日程数据仅存于你的 iCloud：你创建的日程、待办与提醒设置，保存在你本人 Apple ID 下的 iCloud 私有数据库（Apple CloudKit，容器 iCloud.com.frankzhou.ScheduleApp）。数据归你所有，由 Apple 保管，开发者无法访问、读取或导出。
  • 家庭组共享：基于 Apple CloudKit 共享能力（CKShare）实现。你自己创建的日程保存在你的 iCloud 私有数据库；只有当你把日程发布到家庭组时，该日程才会进入 Apple 提供的 iCloud 共享数据库，且仅你邀请的家庭成员可见。共享范围完全由你控制，可随时停止共享。

设备能力与系统权限：

  • 通知：仅用于你自行设定的本地到点提醒（日程/待办闹钟），不含任何广告或营销内容。其中远程（静默）通知仅用作 iCloud 数据同步的触发信号，不会产生任何可见提示，也不承载日程内容。
  • 小组件与灵动岛：小组件与锁屏数据通过设备本地的 App Group 容器在主应用与小组件之间传递，不离开你的设备，不上传任何服务器。
  • 不申请的权限：本应用不申请、不使用定位、通讯录、相机、麦克风、相册、蓝牙跟踪（App 追踪透明度）等权限，工程内无其他任何权限声明。

三、第三方、追踪与广告：均无

  • 无任何第三方代码：工程不依赖任何第三方 SDK——无广告 SDK、无统计/分析 SDK、无崩溃上报、归因或营销推送组件。
  • 不追踪：无 IDFA、无 App 追踪授权请求、无跨应用/跨站点追踪、无追踪 Cookie、设备指纹或本地标识符。
  • 绝不出售数据：我们不出售、不共享、不交易用户数据，不进行任何形式的数据变现，数据不用于广告投放或用户画像。
  • 所有网络请求只发往 Apple：除加载本政策页面外，应用的全部网络请求均为 iCloud/CloudKit 同步，受 Apple 隐私政策约束。本页面托管在第三方静态托管服务（GitHub Pages）上；加载本页是应用对非 Apple 服务的唯一网络请求，且不携带任何账号或设备标识。
  • 我们已在应用隐私清单（PrivacyInfo.xcprivacy）中向 App Store 声明：不追踪用户、不使用任何追踪域名。

四、未成年人保护

  • 本应用是面向一般受众的家庭工具应用，不是专为儿童设计的应用，也不面向任何特定年龄以下的儿童进行营销。
  • 本应用不收集任何人的个人信息（包括儿童）：儿童创建的日程与待办同样只保存在其本人（或家长）的 iCloud 账户中，开发者无法访问。
  • 若家长通过 Apple「家人共享」为儿童创建并管理子账户，相关账户遵循 Apple 规则；共享始终处于家长控制之下，可随时停止。
  • 如你认为我们在不知情的情况下收集了未成年人信息（本应用架构上不会发生），请发送邮件至 {mail}，我们将立即协助删除。

五、数据存储、安全与删除

  • 全部数据存于你 Apple ID 的 iCloud 账户中，受 Apple 的加密与访问控制保护；我们不保留任何服务器端副本。（中国大陆 Apple ID 的 iCloud 数据由云上贵州——Apple 在中国的云服务运营方——依 Apple 政策运营。）
  • 删除应用不会自动删除 iCloud 数据（以便你在新设备恢复）。如需彻底删除：在 iPhone/iPad 上进入「设置 → 你的 Apple ID → iCloud → 管理账户储存空间 → 日程提醒 → 删除数据」；或在应用内删除日程/待办与家庭组；也可发送邮件至 {mail} 获取删除协助。
  • 少量界面偏好（语言、显示设置等）保存在设备本地（系统 UserDefaults），不离开你的设备，也不同步到 iCloud。
  • 本地优先：即使未开启 iCloud 或网络不可用，应用仍可离线记录日程并正常触发本地提醒。
  • 请妥善保管你的 Apple ID 与设备密码——它们是这份数据的首要保护。

六、政策更新

如本政策发生变更，我们将更新本页面并修订顶部的「生效日期」。重大变更（例如引入任何新的数据收集）还将在应用内显著提示。请定期查看本页以获取最新版本。

七、联系我们

如对本政策或你的数据有任何疑问、投诉或删除请求，请发送邮件至 {mail}。我们通常会在 3 个工作日内回复。

支持与常见问题

数据会丢失吗？不会。数据保存在你的 iCloud 中，随你的 Apple 账户保留；删除应用不会删除 iCloud 数据。
换新手机怎么办？在新设备登录同一 iCloud 账户并开启本应用的 iCloud 同步，数据会自动出现。
家庭成员能看到什么？只有你发布到家庭组的日程。未发布的日程保存在你的 iCloud 私有数据库，其他成员不可见。
开发者能看到我的日程吗？不能。数据在你的 iCloud 中，开发者没有访问通道。
提醒没有响？请检查系统「设置 → 通知」中本应用的通知权限，以及应用内提醒是否开启；未登录 iCloud 时应用以单机模式运行，本地提醒仍然有效。
支持哪些语言？10 种：简体中文、繁體中文、English、日本語、Español、Português (BR)、Français、Deutsch、한국어、Русский。
